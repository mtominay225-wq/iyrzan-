About MISTER - X

MISTER - X adalah dashboard demo bertema cyber security untuk belajar konsep keamanan digital dengan aman.

PENTING: Website ini tidak memiliki fitur untuk membobol akun, mencuri data, menyebarkan malware, mengeksploitasi target, atau melakukan serangan jaringan.

Aturan penggunaan

✓ Gunakan pada perangkat dan akun milik sendiri.
✓ Dapatkan izin sebelum menguji sistem pihak lain.
✓ Jangan meminta atau menyimpan password, OTP, atau data pribadi orang lain.
✓ Gunakan pengetahuan untuk melindungi sistem dan melaporkan celah dengan bertanggung jawab.

Teknologi

HTML • CSS • JavaScript • berjalan lokal di browser • tanpa backend dan tanpa pengiriman data.
